## Selected projects

### 🏠 [PlacdAI](https://placdai.com) — Reimagine your space with AI

An AI interior design platform that helps people visualize changes to their own rooms and discover furniture they can actually shop for.

I built and launched an MVP that connects room-image editing with product discovery.

**Built with:** React · TanStack Start · Supabase · Google Gemini

**[Try PlacdAI](https://placdai.com)**

### 🩺 [HealthBot](https://github.com/AayanWasti/Healthbot-official) — Making health information more accessible

An AI-powered health information assistant developed through **AIHealth**. The goal is to make general health information easier to explore through a clear, conversational interface.

**Built with:** React · Node.js · Express · MongoDB

**[Explore the code](https://github.com/AayanWasti/Healthbot-official)** · **[Read the story](https://www.oakvillenews.org/helpers/oakville-high-school-students-create-ai-tool-to-make-health-information-accessible-10397011)**

### 👶 [CareNest](https://devpost.com/software/carenest-q1d4si) — A hackathon project for newborn care

Co-built a prototype combining real-time temperature monitoring with a web dashboard and AI-generated health insights, designed around the challenges of neonatal care in resource-limited settings.

**Built with:** React · TypeScript · OpenAI API · Arduino

**[View on Devpost](https://devpost.com/software/carenest-q1d4si)**

### 🔎 [career-ops](https://github.com/AayanWasti/career-ops) — Open-source exploration

Open-source work around an AI-assisted job search workflow, from evaluating opportunities to improving the application process.

**[Explore the repository](https://github.com/AayanWasti/career-ops)**
